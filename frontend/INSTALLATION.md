# 📱 Installation de HWENDO 2026 sur téléphone

## Sur Android (Chrome)

1. Ouvrez Chrome sur votre téléphone
2. Allez sur l'URL de votre application (ex: http://192.168.1.100:5173)
3. **Option A** : Cliquez sur le bouton "📱 Installer l'app" dans le menu
4. **Option B** : Menu Chrome (⋮) → "Installer l'application" ou "Ajouter à l'écran d'accueil"
5. Confirmez l'installation
6. L'icône HWENDO apparaît sur votre écran d'accueil !

## Sur iPhone (Safari)

1. Ouvrez Safari sur votre iPhone
2. Allez sur l'URL de votre application
3. Appuyez sur le bouton "Partager" (carré avec flèche vers le haut)
4. Faites défiler et appuyez sur "Sur l'écran d'accueil"
5. Appuyez sur "Ajouter"
6. L'icône HWENDO apparaît sur votre écran d'accueil !

## Utilisation hors-ligne

Une fois installée :
- ✅ L'app fonctionne **sans internet**
- ✅ Toutes les données sont sauvegardées localement
- ✅ La synchronisation se fait automatiquement au retour du réseau
- ✅ Les photos/vidéos sont stockées sur le téléphone

## Désinstaller

- **Android** : Appui long sur l'icône → Désinstaller
- **iPhone** : Appui long sur l'icône → Supprimer le signet
